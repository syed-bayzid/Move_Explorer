# Movie Explorer

A responsive Movie Explorer application built with **React** and **TVMaze API**.

### Features

* Browse movies/shows
* Search by title
* Movie details modal
* Responsive design
* React Router navigation

### Tech Stack

* React
* JavaScript
* Tailwind CSS
* React Router
* TVMaze API

### API

TVMaze API — https://api.tvmaze.com/
